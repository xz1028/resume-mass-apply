# 用户说明书

零背景用户指南：从获取软件到真实使用的完整旅程。

## 一、安装

**方式一：分发包（推荐，免安装）**

1. 从项目仓库 Releases 页下载 `resume-mass-apply-green.zip`
2. （可选）核对校验和：同目录 `SHA256SUMS.txt` 中的值应与下载文件一致
3. 解压到任意目录（支持中文与空格路径，如 `D:\我的工具\就业海投\`）
4. 双击 `start.bat`：约 30 秒内浏览器自动打开软件界面

要求：Windows 10/11 64 位；无需安装 Python 或其他任何软件；普通用户权限即可。

**方式二：源码运行（开发者）**——见 docs/developer-guide.md。

**常见安装问题**

| 现象 | 处理 |
|------|------|
| 双击后提示"端口 8000 被其他程序占用" | 关闭占用该端口的程序后重试 |
| 双击后提示"程序文件不完整" | 重新解压分发包并核对校验和 |
| 杀毒软件拦截 | 选择信任放行（PyInstaller 产物的业界普遍现象），或改用源码运行 |
| 浏览器未自动打开 | 手动访问窗口中显示的地址 `http://localhost:8000` |

**卸载与数据**：全部数据保存在解压目录 `data/` 子目录，随目录迁移保留；删除整个目录即彻底卸载。

## 二、演示体验（开箱即用）

首次双击启动会自动进入**演示模式**：

- 自动生成虚构演示简历（一份后端工程师简历，含技能/经历/教育背景）
- 自动授权模拟招聘平台并拉取 593 个演示职位（12 行业 × 23 城市全覆盖）
- 预置 23 条演示投递记录（含已投递/已查看/面试邀请/不合适/投递失败五种状态）

体验完整旅程（约 5 分钟）：

1. **职位推荐页**：点城市/薪资/行业/经验标签筛选；切到"智能推荐"看匹配度排序
2. **勾选职位 → 批量投递**：进入投递清单确认页（可看拦截明细）
3. **确认投递**：任务开始执行，投递任务页每 5 秒自动刷新进度
4. **投递记录与统计页**：看状态流转、状态分布、平台分布、近 7 天趋势图
5. **页面顶部横幅 → "退出演示模式"**：一键清除全部演示数据（授权保留）

> 演示数据全部为虚构（人物/公司均不真实），经行业×岗位白名单约束生成。

## 三、真实使用

1. 退出演示模式后（或首次直接上传）→ **简历管理页**上传真实简历（PDF/Word，≤20MB，可多版本管理、设默认）
2. 同页填写联系方式（必须为有效手机号或邮箱）与求职意向（城市/薪资/行业）
3. **平台授权与设置页**：
   - 模拟平台：输入演示凭证 `valid-token` 可继续本地体验
   - 真实平台（BOSS直聘/智联/前程无忧）：点"启用"→ 确认风险告知 → "打开浏览器登录授权"（在弹出的浏览器窗口中登录您的账号，登录态加密保存、密码不落盘）
4. 职位推荐页筛选/勾选 → 批量投递 → 投递记录与统计页跟踪状态（面试邀请/不合适会横幅通知）

**真实平台须知**：浏览器自动化为非官方通道，存在账号被平台限制/封禁的风险（启用时的风险告知必须确认）；验证码一律转人工（横幅"前往处理"）；投递限流默认 20/小时不可超过 30/小时。

## 四、AI 功能配置（可选增强）

AI 读 JD 算匹配度 + AI 生成定制招呼语，需要您自己的大模型 API Key（软件不内置任何 Key）：

1. **AI 模型配置页**（导航最后一项）→ "新增配置"
2. 服务商七选一：DeepSeek / 通义千问 / Kimi / 智谱 / **华为云磐古大模型** / OpenAI 兼容接口 / 本地 Ollama
3. 填写您自己的 API Key → "测试连通"（显示成功后）→ "激活"
4. 激活后：推荐页出现 AI 评分与理由（渐进刷新）、投递清单出现可编辑的 AI 招呼语

**隐私与降级**：简历默认脱敏手机号/邮箱后发送（"发送完整简历"开关风险自担）；本地 Ollama 模式数据不出本机；未配置或调用失败时自动回退规则评分，功能不受影响。

**华为云 ModelArts 端点示例**：服务商选"华为云磐古大模型"→ 接口地址填您的 ModelArts 端点（形如 `https://<endpoint>.apigw.xxx/v1`）→ 模型名填部署名称 → 粘贴 Key → 测试 → 激活。

## 五、华为云部署形态（可选）

本软件支持部署至华为云云服务器（ECS/轻量服务器）供自己远程访问：

1. 购买一台 Windows 云服务器（或 Linux + 源码运行形态）
2. 将分发包解压至服务器（或 git clone 后源码运行）
3. 在安全组放行 8000 端口，浏览器访问 `http://服务器IP:8000`
4. 数据持久位置：软件目录 `data/`（建议定期备份）

> 本说明为部署指南性质，不承诺托管服务；单账号单机使用为主，请勿对公网开放注册类用途。
> 安全建议：生产使用建议改绑 127.0.0.1 + 隧道访问，避免简历数据暴露公网。

## 六、常见问题与故障处理

| 现象 | 处理 |
|------|------|
| 双击启动窗口闪退/提示失败 | 按窗口内"失败原因 + 处理建议"三要素提示操作；端口冲突时关闭占用程序 |
| 页面空白/无法访问 | 确认 start.bat 窗口未关闭；按 Ctrl+F5 强制刷新 |
| 简历上传失败 | 检查格式（仅 PDF/Word）、大小（≤20MB）、文件未损坏；同名会自动加后缀 |
| 授权失败（41001） | 检查凭证；真实平台重新发起浏览器登录授权 |
| 达到每日投递上限（40902） | 投递设置中调整上限（建议保持保守值） |
| AI 测试不通（43003 等） | 检查 Key/余额/端点地址；磐古填 ModelArts 端点需 OpenAI 兼容 |
| 真实平台职位拉取失败 | 平台页面可能改版（interface_changed 风险事件会横幅提示）；等待适配更新 |
| 数据备份/迁移 | 复制软件整个目录（含 data/）到新位置即可 |
