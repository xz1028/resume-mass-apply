## 录制要点

- 分辨率 1920×1080，鼠标操作放慢 20%（评委可看清点击位置）
- 每个关键功能出现时加高亮圈标注（后期或录屏软件实时标注）
- 字幕全程中文，旁白可选（无旁白时字幕完整覆盖信息量）
- 结尾定格 2 秒：仓库地址 + "Apache-2.0 开源"字样
